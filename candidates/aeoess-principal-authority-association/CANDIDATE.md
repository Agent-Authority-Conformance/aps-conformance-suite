# Candidate: aeoess-principal-authority-association

Six cases on the association between a principal binding and an accepted authority root. In
every case the binding and the root verify, and only the association evidence changes. This is
a candidate under `docs/CANDIDATES.md`. It is not a reviewed fixture and adds nothing to the
lab's schema, failure classes or verifier behavior. The full description is in
[README.md](README.md).

## Submitter

Tymofii Pidlisnyi (Agent Passport System), who also wrote draft-pidlisnyi-aps.

## Normative target

- draft-pidlisnyi-aps-04, Section 19.2.10 (the principal to authority association, which -04
  leaves not established when it cannot be made and defines no artifact for).
- draft-tanase-ain-authoritative-resolution-00, Section 7.3 and Appendix B.7 (non-normative):
  a signed assertion counts only when its source is competent for that principal, scope and
  domain. The fixture's association profile is the submitter's reading of these sections.

The association statement, the profile, the value `inconsistent` and every `X_FIXTURE_` reason
code are local to this candidate. They are not part of either draft and not a proposal for
either.

## Source

This directory. The cases are generated by `generate.ts` against `agent-passport-system` 8.0.1,
the version this repository pins. `sdk.ts` loads the published principal binding module by file
URL because 8.0.1 does not export it from the package root.

## What the cases test

| case | evidence | association | boundary |
|---|---|---|---|
| PAA-1 | none | not established, `X_FIXTURE_ASSOCIATION_NOT_PRESENTED` | not established |
| PAA-2 | a source competent for another domain | not established, `X_FIXTURE_ASSOCIATION_SOURCE_NOT_COMPETENT` | not established |
| PAA-3 | a competent statement past its expiry | not established, `X_FIXTURE_ASSOCIATION_EXPIRED` | not established |
| PAA-4 | two competent sources disagree | not established, `X_FIXTURE_ASSOCIATION_SOURCES_CONFLICT` | not established |
| PAA-5 | one competent fresh source says the principal belongs to another authority context | `inconsistent` (fixture local) | denied |
| PAA-6 | one competent fresh source says they belong together | established under the fixture profile | not decided by the fixture |

Four pairs differ from PAA-6 in one element each (PAA-1, PAA-2, PAA-3, PAA-5).

## Known limitations

- No APS conformance and no AIN-WRP conformance. Neither draft defines an artifact for this
  association.
- The cases cite AIN-WRP -00. The confirmation above was given under -01.
- Six reason codes the checker can emit are not exercised by any case (listed in README.md).
- Revocation state is supplied by the fixture, and nothing beyond the association is tested.
