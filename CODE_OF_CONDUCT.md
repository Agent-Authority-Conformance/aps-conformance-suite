# Code of Conduct

This repository follows the LF Decentralized Trust Code of Conduct.

The authoritative text is published at
https://lf-decentralized-trust.github.io/governance/governing-documents/code-of-conduct/
and it governs conduct in this repository, in its issues and pull requests, and in any venue where
this work is discussed on behalf of the lab.

To report a concern, follow the reporting instructions in that document.
